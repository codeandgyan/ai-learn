# Retrieval-Augmented Generation
RAG is an AI technique that combines the power of information '*retrieval*' with large language models (*LLMs*) to enhance the '*accuracy*' and '*context-awareness*' of AI-generated responses.

# RAG Steps
## Data Ingestion Process (Indexing)
- Chunking:- Break the data into chunks
- Embeddings:- Create Vector Embeddings of each chunk and attach metadata to each each chunk
- Store the Embeddings in Vector Store (DB)

## Data Retrieval Process
- User Query
- Create Embeddings of the User Query
- Search the embeddings based on similarity score from Vector DB
- Search returns *relevant chunks*
- Filter the relevant chunk from the data in my data source

## Data Generation
- Take User Query as input
- Take Relevant chunks as input - system prompt
- Pass the relevant chunk to the LLM along with user query

## Query Transformation
Query transformation in RAG involves *modifying* or *reformulating* a user's query to improve the *relevance* and *accuracy* of the information retrieved from a knowlege base.

### Parallel Query (Fan-out) retrieval  
Parallel query fan-out retrieval in RAG involves generating *multiple*, *semantically similar queries* from the original user query and then retrieving relevant documents based on these expanded queries.

### Reciprocal Rank Fusion
Reciprocal Rank Fusion (RRF) is an algorithm used to combine ranked lists from multiple search systems or retrieval models into a *single*, *unified* *ranked* list. 

Less Abstraction
                                                                    /
    Rewrite the user query  -> Parallel Query (Fan-out) retrieval --   --> Rank the relevant chunks based on a priority order
                                                                    \
More Abstraction

### Query Decomposition
Query decomposition is the process of *breaking* down a complex query into *simpler*, more *manageable* sub-queries.

Chain of Thought Prompting - (Less Abstract):- A step-by-step breakdown of user query to plan how to answer the original user query.

Step back Prompting https://arxiv.org/pdf/2310.06117 - (Abstract):- Enables LLMs to do abstractions to derive high-level concepts and first principles from instances containing specific details. Use few shot prompting.

### Hypothetical Document Embedding (HyDE)
HyDE, or Hypothetical Document Embeddings, is a retrieval method that uses "fake" (hypothetical) documents to improve the answers generated by LLMs.
